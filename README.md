# Computer Networks Labs

Учебный репозиторий с практическими заданиями по дисциплине **«Компьютерные сети»**. Работы покрывают базовые сетевые утилиты, SSH-подключение, парсинг веб-страниц, разработку HTTP API, работу с PostgreSQL, контейнеризацию Docker и настройку reverse proxy через Nginx.

Проект оформлен как набор небольших самостоятельных заданий, каждое из которых показывает отдельный сетевой или инфраструктурный сценарий.

## Что реализовано

| Задание | Тема | Содержание |
| --- | --- | --- |
| `1.looking_for_ping.py` | ICMP / ping | Скрипт запрашивает список хостов, выполняет `ping` и выводит минимальную, среднюю и максимальную задержку. |
| `2.1.ssh_connection.jpg`, `2.2.ssh_connection.jpg` | SSH | Скриншоты с демонстрацией настройки и проверки SSH-подключения. |
| `3.parcer_from_web.py` | Web scraping | Парсер новостей с сайта Rozetked через Selenium с фильтрацией по дате и сохранением результата в CSV. |
| `4.API/` | Flask API + PostgreSQL | API для запуска парсинга сайта, сохранения новостей в базу данных и получения сохраненных данных. |
| `5.Docker/` | Docker + Flask + PostgreSQL | Контейнеризованное Flask-приложение для сохранения URL-адресов в PostgreSQL. |
| `6.nginx` | Nginx reverse proxy | Пример конфигурации Nginx для проксирования запросов на локальный Flask-сервис. |
| `9.IP_4_versus_6.docx` | IPv4 / IPv6 | Теоретическая работа со сравнением IPv4 и IPv6. |

## Запуск отдельных заданий

### 1. Проверка задержки до хостов

```bash
python3 1.looking_for_ping.py
```

Пример ввода:

```text
google.com, 8.8.8.8, nsu.ru
```

Скрипт выполнит несколько ICMP-запросов и выведет статистику задержки для каждого адреса.

### 2. Парсер новостей

Для запуска нужны Python-зависимости `selenium` и `pandas`, а также установленный Chrome / ChromeDriver.

```bash
python3 3.parcer_from_web.py
```

Результат сохраняется в CSV-файл:

```text
waste/news.csv
```

### 3. Flask API для парсинга

Файлы находятся в директории `4.API/`.

```bash
cd 4.API
python3 main.py
```

Примеры запросов:

```text
GET http://127.0.0.1:5000/parse?url=https://rozetked.me/news&time=11.03
GET http://127.0.0.1:5000/data
```

API использует PostgreSQL и ожидает базу данных `news_db` с таблицей `news`.

### 4. Docker-задание

Файлы находятся в директории `5.Docker/`.

```bash
cd 5.Docker
docker build -t networks-url-api .
docker run -p 5001:5000 networks-url-api
```

Примеры запросов:

```text
GET http://127.0.0.1:5001/save?url=https://rozetked.me/news
GET http://127.0.0.1:5001/data
GET http://127.0.0.1:5001/clear
```

Приложение рассчитано на работу с PostgreSQL по адресу `postgres:5432`, поэтому при полноценном запуске нужен контейнер или сервис базы данных в той же Docker-сети.

## Навыки, которые демонстрирует репозиторий

- работа с сетевыми запросами и диагностикой доступности хостов;
- базовое администрирование SSH-подключений;
- получение и обработка данных с веб-страниц;
- проектирование простых HTTP API;
- интеграция Python-приложений с PostgreSQL;
- контейнеризация приложения через Docker;
- настройка Nginx как reverse proxy;
- оформление результатов лабораторных работ в воспроизводимую структуру.

## Статус

Репозиторий является учебным проектом. Код ориентирован на демонстрацию сетевых концепций и практических навыков, полученных в рамках курса.
